## Install

Works in Chrome, Edge, Brave and other Chromium browsers, and in Firefox 140 or newer. Get the files from the
[latest release](https://github.com/aaqidmasoodi/dev-null-plus-plus/releases/latest).

**Chrome, Edge, Brave:** unzip `dev-null-plus-plus-…-chrome.zip`, open `chrome://extensions`, turn on **Developer mode**,
click **Load unpacked** and pick the folder.

**Firefox:** drag `dev-null-plus-plus-…-firefox.xpi` into a window and click **Add**. With only the `.zip`, open
`about:debugging#/runtime/this-firefox` and use **Load Temporary Add-on…**.

Then open [dev-null.sh](https://dev-null.sh). If the toolbar icon shows **!**, click it and allow access to the site.

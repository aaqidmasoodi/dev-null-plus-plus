## Install in Chrome, Edge or Brave

1. Download the Chrome file above.
2. Unzip it. On Windows, right-click it and choose **Extract All**. On a Mac, double-click it. Keep the folder somewhere it will stay, like Documents.
3. Open `chrome://extensions` (in Edge, `edge://extensions`; in Brave, `brave://extensions`).
4. Turn on **Developer mode**, top right.
5. Click **Load unpacked** and choose the unzipped folder.
6. Open [dev-null.sh](https://dev-null.sh). **/dev/null++** is in the menu, under Settings.

## Install in Firefox

1. Download the Firefox file above. Do not unzip it.
2. Open `about:debugging#/runtime/this-firefox`.
3. Click **Load Temporary Add-on…** and choose the file.
4. Open [dev-null.sh](https://dev-null.sh). **/dev/null++** is in the menu, under Settings.

Firefox removes it when it restarts, so repeat these steps after a restart. A version that stays is on its way.
<!-- /firefox:unsigned -->

## Updating

When a new version is out, dev-null.sh says so at the top of the page.

- **Chrome, Edge, Brave:** download the new Chrome file, unzip it into the **same folder** as before, replacing the files, then click the reload arrow on /dev/null++ in `chrome://extensions`. Your settings and AI key stay.
- **Firefox:** install the new Firefox file the same way.
